Link this device

  1. On the computer running Kitsuvo, open Settings → Assistants → Remote access and turn it on.
  2. Choose Link this device below. The next page shows a code.
  3. Paste that code into Kitsuvo, check that the assistant is “Kitsuvo remote control”, and approve it.
  4. Come back and refresh that page to finish.

You control Kitsuvo's separate agent profile, never its signed-in tabs. The link lasts while this browser tab stays open.
